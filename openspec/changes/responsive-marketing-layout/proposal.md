## Why

Маркетинговий сайт зібраний під Figma 1728 exact. Нижче 1727px один inferred-стек (як телефон) розтягується на планшет і малий ноутбук, тож бічний склад 121:55 зникає занадто рано. Окремих tablet/mobile фреймів немає — потрібна гумова адаптація «на око» від 1728 із порогом десктопного складу ~1280, плюс зафіксувати вже змінені хедер, капсули головної, прозорий логотип Danish і новий hover хіт-зон сервісів.

## What Changes

- Design: none (нових Figma-фреймів немає; джерело правди desktop лишається Figma `MvXJfIcOGrrsT82JxAMpDL`, кадр `121:55`).
- Замінити inferred-стек «усе <1728 = телефон» на три діапазони: desktop ≥1280 (при ≥1728 pixel-perfect; 1280–1727 — стиснутий той самий бічний склад), tablet 768–1279 (2-колонка дозволена там, де на desktop уже є колонки), phone <768 (стопка, той самий порядок регіонів).
- Скоуп лише `SiteLayout` і маркетингові сторінки всередині нього. `GsAppLayout`, тахометр і архів не змінюються.
- Адаптація пропорційними ширинами й gutter, **не** повносторінковим `transform: scale()`.
- Хедер за 121:55: Контакти · Проєкти · Майстерня · Події · Благодійність · UA|ENG. Пунктів Прокат і Артефакти в хедері бути MUST NOT (залишаються сервісними плитками на головній).
- Капсули «Актуальні події» і «Проєкти»: default — лише підпис 36px на фото, без блюр-смуги; hover — нерухомий текст і прозора пігулка 440×120; mouseleave повертає default; поведінка обох капсул абсолютно однакова; reduced motion — миттєва зміна.
- Сервісні плитки Веломайстерня / Прокат / Артефакти: hover-кільце навколо хіт-зони кнопки; підпис і іконка не стрибають. Hover на всю плитку-обгортку не вигадувати.
- Логотип Danish Youth House в футері: PNG без непрозорого білого прямокутника (асет з Figma 121:85).
- Не новий sitemap і не нові сторінки. Існуючий маршрут `/events` лишається ціллю пункту «Події» і капсули подій (як у поточному продукті); spec синхронізується з цим, не додає сторінку.

## Capabilities

### New Capabilities

- Немає.

### Modified Capabilities

- `site-chrome`: брейкпоінти inferred-стеку (1280 / 768 замість порогу 1728); навігація хедера без Прокат/Артефактів; прозорий логотип Danish; маршрути маркетингу включають уже існуючий `/events`.
- `home-page`: однакова hover-поведінка капсул без default-блюру; hover хіт-зон сервісних іконок; смуги головної стискаються на 1280–1727, не складаються в phone-стек.

## Impact

- **Код (marketing only):** `src/layouts/SiteLayout.vue`, `src/components/site/*` (хедер, нав, футер, лого), `src/pages/HomePage.vue` і внутрішні маркетингові сторінки/ряди (`ProjectsPage`, `GoldenSprintsPage`, `ArmySupportPage`, `WorkshopPage`, `RentalPage`, `ArtifactsPage`, `CharityPage`, `EventsPage`; `ProjectRow`, `RentalBike`, `ArtifactRow`), `src/components/home/HomeCapsuleEvents.vue`, `HomeCapsuleProjects.vue`, `HomeServiceTile.vue`, `src/styles/tokens.css`, `src/style.css`, асет `src/assets/site/logo-danish.png`.
- **Уже в working tree (зафіксувати, не ламати):** `SiteNav.vue` (без Прокат/Артефактів), `tokens.css` (спільна висота hover-пігулки 120px, прибрані токени default-блюру подій), капсули з нерухомим підписом і hidden-пігулкою, прозорий `logo-danish.png`.
- **Нова робота:** брейкпоінти SiteLayout і внутрішніх колонок; hover `HomeServiceTile.vue`.
- **Поза зміною:** `src/layouts/GsAppLayout.vue`, `TachometerPage.vue`, `ResultsArchivePage.vue`, BLE/архів-сервіси, `server/`.
- **Залежності:** нові npm-пакети не потрібні. Стек без змін: Vue 3 `<script setup lang="ts">`, без Pinia, Axios, Options API.

## Non-goals

- Нові Figma-фрейми, окремий мобільний макет, новий sitemap чи нові сторінки.
- Зміни тахометра, архіву, `GsAppLayout`.
- Повносторінковий `transform: scale()`.
- Pixel-QA на 1366; 1728 лишається джерелом правди.
- Реальна локалізація ENG (UA|ENG лишається візуальним).
- Повернення Прокат/Артефакти в хедер.
- Вигаданий hover на пунктах нав і кнопці Благодійність (лишається лише `:focus-visible`).

## Acceptance criteria

- На ширині ≥1728 головна зберігає склад кадру 121:55 (pixel-perfect desktop).
- На 1280–1727 маркетингові сторінки в `SiteLayout` показують той самий бічний склад, стиснутий пропорційно, а не phone-стек.
- На 768–1279 двоколонкові регіони (де вони є на desktop) можуть лишатися двоколонковими.
- На <768 регіони йдуть стопкою в тому ж порядку, що на desktop.
- У хедері немає Прокат і Артефактів; є Контакти, Проєкти, Майстерня, Події, Благодійність, UA|ENG.
- Обидві капсули головної: default без блюр-смуги; hover — пігулка 440×120 і нерухомий підпис 36px; mouseleave повертає default.
- Hover трьох сервісних іконок показує кільце навколо хіт-зони без зміщення іконки й підпису.
- Логотип Danish у футері без непрозорого білого прямокутника.
- Немає `transform: scale()` на обгортці сторінки `SiteLayout`.
- `GsAppLayout` / тахометр / архів не змінені цією зміною.
- `npm run typecheck` і `npm run build` проходять.
